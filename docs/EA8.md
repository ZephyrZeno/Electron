# EA-8 v0.1 指令与硬件草案

状态：汇编器已经实现；下列 CPU 硬件和执行语义是下一阶段的实现契约，当前版本没有游戏内 CPU。

## 硬件目标

8 位累加器 A，8 位程序计数器 PC，16 位指令寄存器 IR，8 位输出寄存器 OUT，零标志 Z、进位/无借位标志 C；程序 ROM 为 256×16 位，数据 RAM 为 256×8 位。ROM 与 RAM 分开寻址，不支持自修改程序、栈或中断。

指令由两个字节构成：第一个字节是操作码，第二个字节是操作数。ROM 地址以**指令字**为单位递增，不以字节递增。二进制文件按 `[opcode, operand]` 顺序写入；没有操作数的指令低字节为 0。

时序必须由红石电路实现：取指 → 锁存 IR → 译码/读数据 → ALU 稳定 → 写回/更新 PC。每个阶段的时钟间隔以最慢路径的实际传播时间为依据。组合逻辑的中间毛刺不得直接触发寄存器写入。

## 指令

| 指令 | 操作码 | 计划语义 |
| --- | --- | --- |
| `NOP` | 00 | 无操作 |
| `LDI imm` | 01 | A ← imm；更新 Z，C ← 0 |
| `LDA addr` | 02 | A ← RAM[addr]；更新 Z，C ← 0 |
| `STA addr` | 03 | RAM[addr] ← A；标志保持 |
| `ADD addr` | 04 | A ← A + RAM[addr]，保留低 8 位；更新 Z、C |
| `SUB addr` | 05 | A ← A − RAM[addr]，保留低 8 位；C=1 表示没有借位；更新 Z |
| `AND addr` | 06 | A ← A AND RAM[addr]；更新 Z，C ← 0 |
| `OR addr` | 07 | A ← A OR RAM[addr]；更新 Z，C ← 0 |
| `XOR addr` | 08 | A ← A XOR RAM[addr]；更新 Z，C ← 0 |
| `JMP target` | 09 | PC ← target |
| `JZ target` | 0A | Z=1 时跳转，否则顺序执行；标志保持 |
| `JC target` | 0B | C=1 时跳转，否则顺序执行；标志保持 |
| `OUT` | 0C | OUT ← A；标志保持 |
| `HLT` | FF | 停止 CPU 时钟，保持 PC 和寄存器 |

除成功跳转与 HLT 外，执行后 PC 加一，保留低 8 位。复位时 PC、A、OUT、C 清零，Z 置 1；数据 RAM 的清除需要独立电路，不假定断电清空。

## 汇编语法

大小写不敏感，每行最多一条指令。`;` 开始注释。标签使用字母或下划线开头，后续允许数字；标签地址由两遍扫描解析。

支持 `42`、`0x2A`、`0b00101010`。操作数只能是 0–255。程序最多 256 条指令。汇编器拒绝重复标签、未知操作码、错误参数数量、超范围操作数以及跳到当前程序之外的地址。

```asm
start: LDI 5
       STA 0x10
       LDI 3
       ADD 0x10
       OUT
       HLT
```

输出字节：`01 05 03 10 01 03 04 10 0C 00 FF 00`。实体 CPU 完成后，应观察到 OUT 灯组显示 8，然后停机。

## 验收顺序

1. 8 位寄存器、单步时钟和复位：验证逐位保存、载入存档后的状态以及数据/时钟竞争条件。
2. 8 位 ALU：加、减、逻辑运算、Z/C；验证最长进位路径和结果锁存时机。
3. 地址译码与 RAM：选中地址写入、其他单元保持、读取稳定。
4. ROM 与 PC：按地址读取完整指令，顺序递增、条件跳转、复位及 HLT。
5. 控制器：实体红石完成取指、译码、执行、写回；机器码示例输出 8。
6. 再扩展输入设备、显示器和完整计算器界面；评估布线体积与时钟频率。

本模组第一版的原版计算器是上述 ALU 加减逻辑的独立验证样机。生成结构的电路要求与手动搭建的模组元件分开验收：计算器结构只能包含 `minecraft` 命名空间的方块。
