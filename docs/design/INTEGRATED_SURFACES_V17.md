# 一体表面与材质整理 v17

适用版本：Electron: Circuit Foundry 0.9.1-alpha.1，Fabric 1.21.1 / Java 21。

## 玩家看到的变化

端子名称、逻辑门名称、电阻阻值和按钮标识直接位于器件的实体表面。独立薄牌及运行时绘制的悬浮文字已移除。标识不再与底板拉开距离，也不在原表面上叠放第二张相同深度的面。

- 小型器件：端子标识印在底板，逻辑门和 MOSFET 的字样位于真实芯片封装顶面。
- 接线排与配电器件：A/B 母线、输入输出及极性仍可辨识。电压铭牌不恢复，电学规格继续在手册与物品说明中查看。
- 塔顶接线座：原来悬在空中的标签移到相应绝缘瓷片上，导体、瓷片和实际接线位置保留。
- 电站和风机底部接线柜：标签印在柜内端子座远离出线槽的一端，避免线槽挡字，开门可见；关闭柜门不改变标识及线路。
- 金属、塑料、陶瓷小件：按模型的实际尺寸设置 UV，减少整张大纹理被挤到螺丝或细边条上的比例失真。
- 光照、雨水传感器：不再在外壳内部绘制通用继电器活动触点。传感器的检测、耗电和触点规则保持原有逻辑。

## 表面处理与兼容性

`tools/integrate_model_markings.py` 作为旧模型生成器之后的表面整理步骤。它使用已有的高分辨率标识材质，不对文字反复缩放或重采样。

1. 找到薄牌及其背后的实体表面。
2. 把承载面按标识区域切分；保留其它区域原来的 UV 坐标。
3. 标识使用承载面完全相同的平面坐标，并替代该区域原材质。
4. 删除薄牌侧面、背面及内部无效面；芯片本体保持实体结构。
5. 标识随安装面和器件旋转，损坏状态使用烧灼材质。

接线柜同样切分真实端子座的顶面。柜体表面按类型、安装面、旋转与柜门状态缓存网格；不再每帧排版字形或重新计算面片。

此次覆盖 42 类器件、5,082 个世界／物品模型变体，整理 18,392 处薄牌。以本地提交 `27c712b` 为基线，这些模型的面片总数由 809,936 降为 715,861，减少 11.62%。这是全部方向、状态变体的资源统计，不代表同一时刻屏幕上的面片数，也不是帧率提升实测。

没有改变方块 ID、耗材配方、接线端点、碰撞规则和存档格式。已有器件直接使用新模型，原存档无需拆线重建。新教学地图独立安装，不覆盖玩家修改过的旧地图。

## 验证方式

- `python -m unittest discover -s tools -p test_integrated_markings.py`：六面安装的共面深度、完整表面积、无标识下重复面、已切分承载面、塔顶瓷片、无背板报错、UV 比例、封装保留与损坏状态。
- `python tools/integrate_model_markings.py --check --baseline-ref 27c712b`：逐一验证已提交模型；再次执行不应产生更改，并从固定 Git 基线复算面片统计。
- `python tools/check_foundry_assets.py --surfaces`：完整材质引用、模型边界和方块状态检查，以及实际 JSON 模型的离线预览。
- `CabinetSurfaceTest`：柜内端子座标识的区域覆盖、无叠面、柜门开合位置不变，以及出线槽／螺钉不遮挡字样。
- `runInterfaceQa`：真实 Minecraft 客户端渲染六种器件、三种接线柜状态，保存俯视与低角度截图；同时回归手册、PCB 画布和元件盘。
- 发行包还运行 Java 单元测试、Minecraft GameTest，以及新教学世界生成、保存后重载、电路与掉落实体审计。

`client-surfaces-top.png`、`client-surfaces-profile.png` 是真实 Minecraft 客户端帧缓冲截图；`integrated-surfaces-preview.png` 是离线模型预览。没有使用 Computer Use。用户整套光影与资源包组合仍需实际游玩确认。

## 后续资产维护

旧生成器可能生成历史薄牌；运行这些生成器后，应先执行 `integrate_model_markings.py` 再执行 `--check`。新增标识必须放在真实机壳、封装或底板上，不能用偏移文字、透明浮片或相同平面上的重复面掩盖建模问题。动态读数仍由显示屏和仪表 HUD 显示。
