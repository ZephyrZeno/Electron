目标是让玩家在 Minecraft 的一格空间内布置多根细电线，能整理、检修、穿过建筑墙体，也能看清哪些线相连。密度来自真实的独立通路、排线与 PCB，不能用一根外观导线免费承载无限端口。

## 1 三种走线位置

| 位置 | 玩家看到什么 | 支撑和范围 |
| --- | --- | --- |
| 表面线 | 沿地板、墙面、天花板铺的细线 | 附着在具有合适完整支撑面的方块上，可绕暴露的棱边转面。 |
| 线槽内 | 多根线或排线并排，盖子可开合 | 线槽提供机械支撑，一格一段；盖上后仍可检修，不改变电气参数。 |
| 穿墙芯内 | 墙外的端口盖，检修时显示内部通道 | 只连接已安装芯体的相应端口，不允许普通线直接钻进实体墙。 |

初始版本不提供没有支撑的任意空间曲线或电线垂坠物理。跨过通道可架线槽，再在其中布线；这使线路位置、选中和拆除保持可预测。

普通墙块保留原来的方块类型与贴图，线和端口作为附属部件存在。不会为了挂一根线就把石砖替换成只能模仿石砖外观的模组方块。实现时以附属记录保存支撑关系；存档与掉落仍须遵循宿主变化。

## 2 一格能放多少线

### 表面网格

每个面提供 16×16 编辑格。细单线宽 1/16 世界格；规则轨道中心位于网格坐标 `1, 3, 5, 7, 9, 11, 13, 15`，相邻线之间留出可视间隔。端子可位于指定格点，最后一段自动吸附到引脚。

每面两层：底层 L0 与绝缘架高层 L1。L1 通过跨线桥或线槽内置隔层支撑；不能把线硬挤进已有线的同一体积。对于贯穿面的平行直线，一个面每层 8 个普通单芯轨位，两层合计 16 个。

| 线型 | 每层占用轨位 | 一个空面的单层平行容量 | 导体预算 |
| --- | --- | --- | --- |
| 普通绝缘单线 / 细信号线 | 1 | 8 根 | 每根 1 |
| 双芯电源线 | 2 | 4 条，即 8 芯 | 每条 2 |
| 8 芯排线 | 2 | 4 条，即 32 芯 | 每条 8 |
| 16 芯排线 | 4 | 2 条，即 32 芯 | 每条 16 |
| 粗电缆 / 工业电缆 | 2 | 4 根 | 每根 1 |

**一个世界格的总预算为 64 个导体通过量，六面、两层和同格附属芯体共享。** 一条导体在同格内连续转弯只计一次；离开后再进入的独立段另计。每格另外限制 128 段压缩直线/弯段，防止用一个导体画满数千个锯齿绕过复杂度限制。

因此，“每面 16 根普通直线”不表示六面可以无条件铺满 96 根再叠加无限排线。放置预览同时显示几何位置和剩余预算，如“本格导体 48/64，目标排线需要 16”。预算用完会在确认前拒绝，库存不扣。

这组数值是实现和压测起点，尚不是已达到的性能指标。第一段交付必须支持多根独立线、两层跨越和穿墙；可调容量必须公开配置，不能悄悄降级成单线方块。

### 多芯线的含义

8/16 芯排线内部每芯独立，端口编号从 0 开始。可用为并行数据、多个按钮或地址线，但不会自动创造总线协议。排线的电源线必须显式分配；“8 位数据 + 电源 + 地”需要十个导体，不能塞进一条只有 8 芯的排线却不扣材料。

排线两端必须连接同芯数插座或分芯端子。16 芯接 8 芯需要转换映射，只能接其中八芯，另外八芯显示未接。屏幕协议总线也有实际电源和数据端子，不因名叫数据线就可以穿越未连接区域。

## 3 放线操作

### 普通路径

1. 将指定线材装入空线轴，手持后指向端子或可用表面，显示吸附点。
2. 右键确定起点，再指向终点，显示路径、总长度、材料余额、电压域提示、途经格的容量。
3. 滚轮切换候选路径；蹲下滚轮选 L0/L1；辅助键增加拐点。可以锁定某一面，防止自动绕到建筑背面。
4. 确认预览后，服务器一次校验全路径和权限，再扣除精确长度并放置。失败时指出受阻段，其他段不偷偷落地。
5. 要分支，选既有端子或先安装接线端子；不会在任何擦边点自动生出分支。

默认自动路径选择最短的可用表面路线；多条等长路线优先少转面、少跨层。自动路由只在玩家选定的局部范围找路，初始上限 32 格；更远距离可用拐点分段规划。预览始终显示跨线桥和端子所需材料。

线轴一次只装一种线型，可存 1,024 格长度及不足一格的余量；改颜色无需重铺，但不能把细信号线改颜色后变成粗电缆。长线路可以在收纳柜补料；库存不足时允许保存计划，不会先铺半条再给出“完成”。

### 精密选择

正常模式使用大范围吸附，不要求玩家准确点到一个像素。持钳/探针时出现“候选线列表”，滚轮依次选中同位置不同层、不同芯和不同面；被选线加粗高亮，另一端标签同时显示。

检修视图可隐藏非选网络、只看某一层、显示端口名和芯号。长按选择键进入局部正视编辑视图，尤其适合天花板与柜后线路。退出后玩家位置不变。

剪线预览显示将断开的设备，确认只移除当前段。拆除整格需明确选择“全部部件”，避免误把一束 16 芯排线连同电源一起清掉。

## 4 接通与绝缘规则

| 情况 | 默认结果 |
| --- | --- |
| 两条线在不同层交叉 | 保持绝缘，没有节点。 |
| 两条线在同层路径交叉 | 不允许体积重叠；自动建议上跨层或绕行。 |
| 两条线端点落在同一个接线端子 | 同一节点，电气相连。 |
| 两条线靠近、擦边或颜色相同 | 不连接。 |
| 不同颜色的线接在同一个端子 | 相连；提示标签不同，不自动隔离。 |
| 两个端子有桥片 | 合并为同一节点，检修时画出实体桥片。 |
| 端点没有落在任何端子 | 开路，显示末端帽和未接标记；可作为待布线状态保留。 |
| 排线相同芯号通过对应插座相接 | 仅该芯相连；其他芯保持独立。 |
| 两个推挽输出接到同一网络 | 允许玩家形成该电路，但给出争用诊断并按电气模型处理。 |

端子、桥片和芯体都有有限的接触电阻与额定值。绝缘导线默认不会因经过金属方块就把整面铁墙带电，铁墙也不能免费当回线。若未来增加裸铜母排，应另设导体部件和模型；本版不隐式引入。

普通线不能从墙正面直接穿到背面；贴着边缘绕过去可以，穿过内部需要穿墙芯。跨线桥只跨越一条局部线束，不跨越实体墙。

## 5 六面穿墙芯

### 一格厚墙的默认安装

穿墙芯分 1、2、8、16 芯和工业双芯型号。每个成品包含内部导体、绝缘套，以及**两个端口盖**。玩家选中正面时，另一盖位于对面，不另外消耗材料。

安装在六个方向都允许：北↔南、东↔西、上↔下。例：把双芯安装在墙的西面，西/东各出现 `0` 和 `1` 号端子，内部默认 `西0↔东0`、`西1↔东1`。两芯互相绝缘，电源正负各接一芯。

```text
墙外电源 + ─── [西 0] ═══ 穿墙芯通道 0 ═══ [东 0] ─── 室内负载 +
墙外电源 − ─── [西 1] ═══ 穿墙芯通道 1 ═══ [东 1] ─── 室内负载 −
                         同一个原有墙方块
```

放置步骤：手持芯体或穿墙钻 → 指向墙面位置 → 预览两侧端口、芯数、额定值 → 确认扣一件并安装。普通手工安装用时 20 游戏刻，期间移动或墙改变则取消，不扣材料。

另一面不可见时，预览用半透明轮廓显示出口。若出口被设备堵住，允许安装芯体但出口显示“遮挡，尚未连接”，不得凭空连上后方任意设备。可以先施工墙芯，再从内侧布线。

### 端口方向和防镜像

芯号由核心的局部坐标定义，不按玩家站在哪侧重新从左数一次。每面端口显示自身丝印和 `0` 号三角标记；背面布局视觉上可以镜像，但内部 `0↔0` 保持不变。

旋转预览时连线跟随整个部件旋转；安装后更改朝向属于改线操作，需要断开受影响连接并预览，而不是只把贴图转了却保留错误引脚。上下表面给出局部朝北箭头，避免天花板端口没有可读的“上”。

### 一块墙内的多个芯体

墙面提供四个安装槽：局部坐标 `(4,4)`、`(12,4)`、`(4,12)`、`(12,12)`。每芯体占一个贯通体积及对应端口面区域；可以装多件，但必须通过体积碰撞和全格 64 导体预算检查。

例如一格墙可以装两套相互独立的双芯电源端口，再装一条 8 芯信号通路；它们不会因为都在一个墙块里自动连接。新装入的正交芯体若与现有贯通体积相交，应改槽位，或明确使用现有芯体的侧面扩展。

一个 16 芯芯体的端口面板覆盖所选四分之一面区域，分芯在交互界面和面板排针中完成。芯数增加意味着更多内部导体和材料，不把 16 个世界粗线端子硬挤成互相重叠的碰撞体。

## 6 侧面引出与芯号映射

已有芯体可以用端口盖增加第三至第六面出口。新增盖**默认所有引脚断开**，界面会选中“按同号连接”的建议；必须由玩家确认映射后才通电。这样可以先贴上出口而不突然把正在运行的六面线路短接。

例如已有西↔东双芯，要向上层房间分支：

1. 在上表面给同一芯体装一个双芯盖。
2. 螺丝刀打开映射页，指定 `上0 → 内部通道0`、`上1 → 内部通道1`。
3. 预览显示西0、东0、上0 为同一节点；1 号通道同理。确认后才接通。

一个外部针脚最多映射到一个内部通道，多面可共同接入同一通道作为分支。若要把内部通道 0 和 1 合并，必须添加明确桥接，默认不允许通过误点让一个针脚绑定两个通道。

映射页使用“面名 / 引脚号 / 网络名 / 电压域 / 当前电压”，以连线图展示选择。可交换两个通道以修正位序，交换前显示影响的端口。附属端口没有内置电源、隔离和逻辑，映射只改变金属通路。

盖子只能接入同型号或明确兼容的芯体；工业盖不能直接装到普通信号芯上。低压电源和信号若共用多芯体，需要每芯额定值均满足，界面会列出电压域差异；工业高压芯与信号芯之间需保持专用绝缘分区。

## 7 厚墙和连续通道

两格厚墙需要两个芯体，三格厚墙需要三个。穿墙钻可以选轴向、最大深度和型号，一次预览连续 1–8 格，每格检查宿主、碰撞、预算和权限，再整体安装。

```text
外部线 ─ [端口 | 墙 A 芯体 | 内盖] [内盖 | 墙 B 芯体 | 端口] ─ 室内线
                      对齐接口逐芯耦合
```

相邻墙芯只有在轴线、型号、安装槽和针脚映射对齐时，边界内盖才自动耦合；接触位置与芯号可以在检修视图核对。移除中间任意墙块/芯体，整段对应通道立即开路，不允许两端隔着空气继续通信。

墙中要转弯时，在转角墙芯增加侧面盖，并使侧面盖与下一格墙芯相对。跨过两格的直钻不会绕过中间的容器或基岩。材料不足、某格无权限或宿主不支持时整次预览失败；也可由玩家改成逐格施工。

厚墙内部盖属于芯体本身，不再消耗额外端口盖；只有新增第三面及以上出口才消耗 W17。撤下厚墙通道按实际芯体件数回收，不把成对盖另外掉落成可重复使用的整件。

## 8 宿主和特殊方块

| 对象或事件 | 完整目标版行为 |
| --- | --- |
| 普通完整立方体 | 允许六面附着与穿墙，含石头、石砖、木板、羊毛、混凝土、玻璃等白名单材质。 |
| 半砖、台阶、栅栏、活板门、非完整碰撞体 | 初期只允许适配的完整支撑面铺表面线；不安装贯穿芯体。可用独立接线盒跨接。 |
| 箱子、熔炉及其他有方块实体的设备 | 不钻穿；设备自身有 Electron 专用接口时连接该接口。 |
| 基岩、传送门、流体、空气 | 不作为可钻墙宿主。空气中使用线槽支架。 |
| 贴线宿主被拆除或爆炸破坏 | 相关表面线和附属端口失去支撑，断开并掉落可回收件；线槽若有自己的有效支撑可保留。 |
| 活塞推动带附属件的方块 | 第一版阻止该次推动并提示需要先拆附件；不复制、不悄悄丢线。普通无附件方块仍按原版规则。 |
| 仅贴图/状态变化且支撑形状不变 | 保存附件；若变成不兼容支撑形状，则按失去支撑处理。 |
| 指令或外部模组替换宿主 | 服务器重新校验，清除失效连接并只回收一次，不能保留隐形通路。 |
| 水浸 | 完整线皮本体保持绝缘；普通裸端子判定湿接故障并断开该端口。密封线槽与密封端口可水下工作。首版不求解整片水的导电网络。 |
| 火焰/熔岩 | 按游戏热源使非耐热线逐步损坏，遵循故障模式设置。 |

湿接故障规则是游戏简化，界面明确显示原因；擦干后未损坏的端子可恢复，烧坏的不能自动修好。W21 密封线槽同时密封其覆盖的端子，穿墙端口可用同配方的密封圈附加到盖内：每个盖消耗 M03×2，不改变芯数和额定载流。

支持面白名单和接触体积属于实施验收内容。不能只因为方块看起来是一整块就绕过容器、权限或方块替换规则。

## 9 长度成本与回收

路径长度以 1/16 世界格为一个固定整数单位，不用浮点累计。转面沿实际中心线路径计长，厚墙芯的内部长度由芯体配方覆盖，不再次扣外部线材。

例如在同格铺四条各 12/16 格长的单芯线，总消耗 48/16 = 3 格线材；拆除其中一条，线轴返还 12/16。把一格长的线反复剪成 16 段再取回，合计仍只是一格长度。

排线按束长度扣对应 W04/W05 材料，一格 8 芯排线不能拆出八格普通粗电线；若选择分解，仅按原配方的细线/绝缘材料账本回收。剪断排线默认断全束；要单独断芯，必须在分芯端子处操作。

端子、跨线桥、芯体和盖子的库存分别扣除。线路先移除，连接关系更新，再结算掉落；多人同时剪同一段仅首次成功的请求能取得回收物。

普通完整线允许全额长度回收，鼓励改造建筑；烧损长度转废料，按内容表回收。已有线不能重新提交铺线请求来重复扣料或重复取得掉落。

## 10 电气和仿真边界

电阻等于每格电阻乘长度，加上接点和芯体电阻。全格同一个颜色不等于全格同一个节点；每根线、每个端口和每个通道都有实际拓扑身份。

同格多线也不自动共享回线。两盏灯的四根独立线可以分别来自两个隔离电源；只接信号而没有参考或隔离器，电气检查必须能说明信号参考缺失。

工业线与低压信号可出现在同格，但需要独立的工业绝缘槽分区，占据自己的轨位和预算；不能因颜色不同就免于绝缘检查。游戏不默认计算相邻线的寄生电容、串扰、射频、天线或电磁辐射。电容、电感等储能必须来自实际器件或明确模型。

长静态线段可在仿真中压缩，但必须保存沿程映射，以便显示哪一段过热、哪里压降大、哪处断开。测量中间测试点时可还原对应节点结果，不把所有测试点读成电源端电压。

网络跨卸载区块时采用主设计的网络暂停规则。无权修改的线路仍可在允许的观察权限下看到外观，检修数据和内部连接按服务器权限开放。

## 11 默认颜色与可读性

| 用途建议 | 颜色 | 同时显示的符号 |
| --- | --- | --- |
| 正电源 | 红 | `+`、电压档位 |
| 回流/GND | 黑 | `−` 或 `GND` |
| 数据信号 | 青 | `D0…` 或自定义网络名 |
| 时钟 | 黄 | `CLK` 和脉冲符号 |
| 控制 | 灰 | `EN / RESET / CS` |
| 模拟采样 | 绿 | `ADC` 与波形符号 |
| 存储区域 | 紫 | `ADDR / DATA` 分别标注 |
| 输入/输出模块 | 黄绿 / 白 | `IN / OUT` 和方向箭头 |

这些是初始预设，不限制玩家改色。标签笔改色免费，不生成染料，也不改变物料、线型、电压或连接；本体制造中的有色透光件仍使用染料。红石蓝图继续按算术/输入/存储等模块使用彩色羊毛，与这里的导线标签各自说明。

工业端口另加高压符号和额定牌；正常低压端口显示正负和芯号。不开检修模式也应看清最重要的方向，远处则以线束和机柜轮廓保持简洁。

## 12 必须通过的连接案例

以下是实施后的验收目标，本次文档工作没有宣称这些已经运行通过。

1. 同格四根线组成两个独立电源回路，分别开关，互不串电。
2. 同面底层与上层各走八根普通平行线；选择、测量、拆除任意一根准确命中。
3. 8/16 芯排线逐芯传入固定测试码，另一端位序一致，超过 64 导体预算不扣料。
4. 六个安装面分别安装双芯、8 芯和 16 芯墙芯；另一面芯号不因观察方向镜像错位。
5. 给第三面加端口盖，未配置时开路，确认映射后仅指定通道相连。
6. 一格与多格厚墙逐芯通断正确；取走中间芯体立即断路，放回并连接后恢复。
7. 墙内多芯体彼此绝缘，碰撞预览拒绝不可能的占位。
8. 导体共节点但颜色不同仍相连；同色线擦边或跨层不相连。
9. 破坏宿主、被外部替换、活塞推动、进水和爆炸时没有隐形节点或重复掉落。
10. 把短线拆成最小段反复铺拆，材料总账保持；排线分解不能升级成免费粗线。
11. 多人同时安装/拆除同一位置，至多一次扣料或返还，剩余库存正确。
12. 区块保存加载后端口朝向、通道号、映射、线长、电池能量和故障位置保持。

实现优先顺序为：多导体容器与选择 → 独立节点与两层跨线 → 六面直通墙芯 → 厚墙耦合 → 侧面映射 → 排线/线槽/高级检修。各阶段都沿用同一份坐标与连接契约，避免后续换表示方式导致玩家已铺线路报废。
