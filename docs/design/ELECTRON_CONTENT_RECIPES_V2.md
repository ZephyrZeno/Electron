## 1 配方记法与加工规则

| 记号 | 工位 | 时间和能耗初案 |
| --- | --- | --- |
| C | 原版工作台，无序合成；每份输入占一个格，单次输入合计不超过 9 | 即时，无额外电能。容器返还按原版规则处理。 |
| F | 原版熔炉 | 200 游戏刻；消耗对应燃料燃烧进度。 |
| A | 手工装配台 B01，具备分组材料槽 | 默认手工装配 100 游戏刻；不需电力，超出九格的物料可堆叠放入。 |
| P | 精密电子工作台 B02 | 每批 100 游戏刻，12 V、10 W，即 50 J；未通电时可设计，不能加工。 |
| U | 自动装配机 B08 | 使用原 A/P 配方及 PCB BOM，默认每批 40 游戏刻、30 W，即 60 J。 |

表中 `M01×8 + M03×1 → 8` 表示消耗八份铜线芯和一份绝缘带，产出八份目标物。省略箭头时产出 **1**；工具、机壳等默认也是 1。工具不在配方中列作消耗物，工位要求的工具放在工具槽内。

`A` 工序装配带焊脚的元件/设备时，另消耗 **1 份 M06 焊料和 1 点焊笔热量**；材料加工、机械工具、线材、端子、线槽、手摇机构、空机壳、无源连接件和空板不需要此附加消耗。表中带 `焊` 的配方才应用这条规则，其他 A 配方不自动加料。`P` 工序中带 `焊` 的配方另消耗 1 份 M06，热量已计入 50 J。

基础焊笔 T06 一份煤/木炭补充 64 点热量；首次合成包含的煤提供这 64 点，余量保存在工具上。精密台和自动装配机不扣手工焊笔热量。PCB 的焊料按实际焊盘数单独计量，不能再叠加固定焊料费。

原版材料写中文名；“木板”“木棍”“染料”“羊毛”等用原版物品标签。同色配方要求相应染料，无色基础件不要求染料。每个配方都可在电子手册查看；未来配方查询模组适配不影响手册可用性。

| C07 | 红/绿/蓝/白，每型固定模型与极性 | 对应颜色 M13；RGB 三芯发光封装另由三颗不同色 LED + M13×1 在 A 合成，产出 1。 |

默认逻辑门每 IC 四单元；NOT/BUFFER 同样四单元，避免配方说明与内部可拆解数量不一致。门 IC 的未接输入应显式处理，电气检查提供推荐上拉/下拉。

## 14 PCB 工艺与拆解结算

空板已包含铺铜余量，制图不按路径无限收取整张铜箔。为使复杂布线仍有成本，空板提供固定铜箔预算：B03 64 个板内单位，B04 512 个，B05 2,048 个。超过时，每额外 M02 提供 64 个单位；线宽为两格则每路径格计两单位。过孔消耗 M07：每个触点材料可制造 8 个过孔；余量保存在工位，不向上取整复制材料。

制作实体板的材料为：一张空板 + 实际器件 BOM + 超额铜箔/过孔材料 + 焊料。每份 M06 提供 16 个焊点，工位保存余量；同一焊盘返工消耗新焊料，吸锡得到污染焊料，不能直接等量补回可用焊料。手工台可加工 B03；B04/B05 需要精密台及相应附件。

合格板量产时，每个实例重新扣 BOM，保留相同设计但重新创建实例电量和状态。以另一个已制成模块作为器件时，必须投入那个模块本体，不能只放一张设计纸；展开视图不额外返还模块内部材料。

回收按**投入账本**处理：

- 未焊完且未损坏的元件能直接取回；已焊元件需吸锡，默认回收元件本体，不额外再给其材料。
- 世界完整导线按准确长度返回对应线轴；烧断部分成为废线，铜回收为实际铜投入的 50%，余数记在回收工位。
- 损坏的器件由 B15 拆成原始 BOM 中铜/铁/金质量的 25% 对应废料，绝缘、半导体和已用焊料不返还。
- 废料只在累计达到一份原材料时产出，不让廉价小件每次四舍五入得到一粒金属；处理过的账本标记已清算。
- 电池及储能板先保存或耗散实际剩余能量；拆解不能既输出满电池又输出材料。
- 回收工位加工一批用 12 V、10 W、100 游戏刻；无源拆取完整件可在手工台完成。

收纳柜可以区分“新件、已测良品、未知、坏件”。材料表中的废料、焊桥、烧焦芯片是既有物品状态或可回收材料记录，不另设可刷配方。

## 15 现有红石器件的保留配方

本节根据当前仓库 `src/main/resources/data/electron/recipe` 核对，为**已经存在的配方**。这些方块继续直接处理原版红石；本次完整设计不把它们改成需要供电的微型 IC。

八种门均为有序配方，产出 1：

```text
红石粉   红石火把   红石粉
平滑石   中央材料   平滑石
平滑石   平滑石     平滑石
```

| 已有方块 | 中央材料 |
| --- | --- |
| 与门 AND | 铁锭 |
| 或门 OR | 铜锭 |
| 非门 NOT | 金锭 |
| 异或门 XOR | 石英 |
| 与非门 NAND | 青金石 |
| 或非门 NOR | 紫水晶碎片 |
| 同或门 XNOR | 钻石 |
| 缓冲门 BUFFER | 煤 |

已有二进制存储方块同样产出 1，把上方中央红石火把换成中继器、中央材料换成比较器，其他相同。旧 XNOR 配方含钻石是当前事实；如果未来平衡调整，应明确写迁移说明，而不是在设计稿中声称现有配方已经改变。

EA-8 汇编器是现有软件能力，当前没有已实现的 EA-8 CPU 方块或 E32 板。现有计算器结构由生成命令放置，所列电子配方不改变它的原版运算性质。

## 16 生产链自检

| 目标 | 可用制造链 | 要避免的循环 |
| --- | --- | --- |
| 第一只 LED | 工作台 → B01 → M09/M13 → C07 | 不要求先有电炉或 PCB。 |
| 第一次测量 | B01 → 线圈、保险丝和外壳 → T08 | 不要求先制作 E32 或显示屏。 |
| 第一套电源 | B01 → 手摇源或燃料源 → W01/端子 | 不要求电动机先运行。 |
| 第一台精密台 | B01 → 通孔板、稳压、电容、焊笔 → B02 | 不要求 B02 才能制造其关键控制件。 |
| 第一块标准板 | B02 + 上游电源 → B04 → 扣 BOM 制板 | 编辑免费，制造才扣电和料。 |
| 第一台自动机 | B02 → E32/驱动；B01 → 机械部件 → B08 | 不要求自动机制造自身控制板。 |
| 第一次工业供电 | 燃料源/电池组 → E17 → E15 → E14 → E13 | 先有有限能源，再有 48 V 和交流，不凭空产生市电。 |

最终数据化时，每项配方需要检查依赖可达性、变体数量、返还容器、实例状态迁移、批量产量与拆解上限。本文数值尚待实际生存游玩验证，不能仅因生产链能连通就认定平衡已经完成。
