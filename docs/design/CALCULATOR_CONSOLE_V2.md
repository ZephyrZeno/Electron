# Electron: Circuit Foundry — 计算器操作平台 v2

**Minecraft 1.21.1 / Fabric / Java 21 · 2026-10-02**

操作台已接入现有模块化十进制计算器蓝图。输入、寄存器、定时、四则运算和灯屏均使用原版方块；Java 负责生成蓝图、放置结构、初始化空白状态和中文告示牌。该功能现在属于独立 `electron_calculator` 模组，与主线分开构建和安装。具体验收证据及等待时间记录在 [计算器 README](../../calculator/README.md)。

## 操作方式

告示牌标识数字与功能，玩家按旁边的原版石按钮。每次按键后等待“输入就绪”灯亮，再按下一键。

alpha.4 修复了没有输入时误触发忙与缺项错误的问题。生成或修复后，编辑、影子与执行寄存器均为空白，无需先按 C。忙与错误告示牌标的是指示灯用途，灯亮才表示对应状态。

~~~text
1 → + → 1 → =             下方结果屏：0002
1 → 2 → × → 3 → =         下方结果屏：0036
9 → − → 1 → 2 → =         下方结果屏：0003，负数指示灯亮
1 → ÷ → 6 → =             下方结果屏：00.17
9 → 9 → × → 9 → 9 → =     下方结果屏：9801
~~~

甲、乙两个操作数均为 00–99。此版支持一个二元表达式，没有括号、优先级或连续表达式求值。计算结束后按数字会开始下一道题；此前结果继续保留，直到再次运行或清空。

| 按键 | 行为 |
| --- | --- |
| 0–9 | 向当前操作数追加一位，允许前导零；第三位拒绝并亮输入错误灯。 |
| +、−、×、÷ | 输入甲数后选择运算；乙数尚未输入时可以替换运算符。 |
| = | 表达式完整时保存执行快照，启动原版红石运算。缺项时亮输入错误灯。 |
| C | 清空输入、执行快照与错误，并执行零输入，使结果回到零；需要等待完成。 |
| ← | 删除当前操作数的末位；乙数为空时撤销运算符。 |
| 输入就绪灯未亮 | 按键不接受，也不排队。请逐键输入。 |
| 多键重叠 | 本次事务拒绝，保留已有数值并亮输入错误灯。 |

## 实体布局与屏幕

整机向 +X、+Z 延伸。原算术核心保留原有坐标，新增操作台与立式屏幕位于前方右侧；控制器与连接线位于其后方，定时中继器铺在上层。

当前蓝图为 515×209×256，含 677,866 个原版方块，另加中文告示牌。旧平面灯屏与独立支线共清理 3,582 个方块；仍向立式屏幕供电的共用线路保留，原灯块支撑改为普通羊毛。清理不移动算术模块。

屏幕正面为 **105 格宽、76 格高**，有白色混凝土边框、黑色底板、厚边与支架。下方四位结果使用 18×36 格的七段布局，上方显示甲数与乙数各两位；中间四个标有“加、减、乘、除”的指示灯表示所选运算。数字显示保留前导零。

每个竖直灯像素使用朝向灯的中继器驱动，灯的正面与侧面留有绝缘空隙，避免侧向红石粉不供电或强充能灯把信号反馈给自己的输入线路。

负数使用独立负数灯加绝对值显示；除法亮小数点灯，保留两位小数。除零亮运算错误灯，错误时数字不能作为有效结果。屏幕旁有中文说明。这里的“立体显示屏”是世界中竖立、有厚度的实体机架，像素位于同一正面。

一排 14 位红石灯显示结果寄存器的二进制值，左高右低。除法保存放大 100 倍的值，例如 00.17 对应整数 17。负号、小数点与错误状态另外保存。此版没有独立保存/读回按钮或可寻址 RAM。

## 电路结构

~~~mermaid
flowchart LR
    B[数字与功能按钮] --> K[铜灯按键请求存储]
    K --> N[编码、追加、退格与有效性检查]
    N --> T[影子锁存器]
    T --> Q[编辑状态与执行快照]
    Q --> I[上方输入灯屏]
    Q --> A[已有四则运算核心]
    A --> R[14 位结果与状态寄存器]
    R --> D[下方结果灯屏与二进制灯]
    K --> C[中继器延时序列]
    C --> T
    C --> Q
    C --> K
    Q --> E[原版运行锁存与完成延时]
    E --> R
~~~

每个按键用原版铜灯保存一次请求，按钮松开后仍可采样。两组各 44 位的锁存器依次采样与提交，避免一个按钮脉冲反复追加。执行快照只在有效等号或清空时更新，正常输入不修改运算参数。

六路时序由原版中继器延时轨道生成，顺序打开和关闭影子采样、正式提交、请求清理窗口。等号另触发铜灯运行锁存与保守完成延时。忙信号锁住按键接收中继器，完成后重新亮输入就绪灯。

运算期间结果寄存器开放，让实际算术核心传播；保守等待结束后关闭并保持结果。**忙灯亮时屏幕可能出现中间值，以就绪后的结果为准。** Java 不读按键、不计算结果、不切换灯屏、不检测世界更新队列来宣布完成。测试夹具会检查更新队列，用于验证固定硬件等待是否足够。

生成或修复阶段载入一次空白初始状态：这是原生测试清空电路后采集的方块状态，与蓝图指纹匹配，只消除放置瞬态和恢复空白寄存器。修复替换与初始化时只取消计算器位置的计划更新，保留模块间其他方块的计划更新，避免旧电路在逐批替换时继续传播信号；结束后不再监测或改动计算器。

## 生成与复现

代码位于 top.lacrus.zephyrzeno.electron.BluePrint。ConsoleCompiler 读取现有 modular-calculator.ebp，添加 KeypadCircuit、ConsoleLayout、定时轨道和连接线，不重做已有算术模块。基础逻辑、锁存器与加法器使用固定模板，模块之间自动布线。

~~~powershell
.\tools\gradle.ps1 compileCalculator
.\tools\gradle.ps1 compileConsole -PkeypadOnly
.\tools\gradle.ps1 compileConsole
Copy-Item build\console-calculator.ebp src\main\resources\data\electron\calculator.ebp
.\tools\gradle.ps1 runGametest -PconsoleWhole -PcaptureStartup
Copy-Item build\calculator.startup src\main\resources\data\electron\calculator.startup
.\tools\gradle.ps1 runGametest -PconsoleWhole
.\tools\gradle.ps1 runGametest -PconsoleWhole -PrepairOnly
.\tools\gradle.ps1 build
~~~

build/keypad.ebp 是可复用的前端蓝图；build/console-calculator.ebp 是最终整机蓝图。编译器只恢复布局匹配的布线断点。发行 JAR 内置压缩蓝图和空白初始状态；改动蓝图后必须重新采集初始状态，保留原 alpha.3 的 calculator-legacy.ebp 修复参考。

已有存档中的旧结构不会因换 JAR 自动改变。alpha.3 按钮计算器使用 `/electron calculator repair x y z`，坐标为原生成起点。命令先核对全部原结构位置，发现无关方块则拒绝开始；随后删除旧屏幕和独立支线，恢复线路并清空输入与结果。整个结构须保持加载。更早的拉杆计算器不属于这个命令的匹配对象。
