# Electron: Circuit Foundry 0.5.1-alpha.1

本版范围是电气故障反馈、容器水、逐层取水、模型细化和矮型插排。计算器仍为独立模组，主线不依赖或调用它。

## 电气故障

架空电缆和双端固定的垂直悬线检测真实碰撞面、水面、其他悬线及生物。贴面线路保留绝缘支承规则，不会因为贴着台面就对台面短路。高压贴面导线仍有近距离接触危险。

| 相对本网络参考回路的电压 | 空气净距，格 |
| --- | ---: |
| ≤48 V | 不触发高压空气放电 |
| ≤300 V | 0.45 |
| ≤6.6 kV | 1.2 |
| ≤11 kV | 1.6 |
| ≤24 kV | 2.4 |
| 更高 | 3.5 |

这些是为 Minecraft 尺度设定的游戏参数。运行网络仍是直流等效模型；表格不作为现实安装距离使用。300 MV 雷击峰值是瞬态事件，不会把整张供电网变成持续 300 MV。

漏电和触电作为被动电阻支路参与原来的求解器，使用本网络电源回线作为简化接地参考。只有实际电流 ≥2 mA、耗散功率 ≥0.1 W 才触发持续效果。被动支路不能产生电能，断电、限流、保险丝和断路器仍控制后果。独立电源岛之间不会仅凭坐标相近就把各自的任意电压零点当成电势差。

视觉包括有真实起止坐标的蓝白分叉电弧、内层亮芯、外围微光、受重力影响的橙色火花、过热烟、发红的导体和熔断碎段。火花遇到碰撞面停止显示。局部闪光使用原版光照引擎，通过只在空气格出现、3 刻后清除的不可碰撞光源实现；不覆盖固体或水，不引入光影包。

高压源输出严重塌陷、等效闭路电阻很低时，在最大电流线路上显示短路电弧。细线超过 250 mA、电缆超过 5 A 后仍按原有累积热量规则烧断并掉落一份废料；特效定位改为实际曲线中点，垂直线和架空线不再错误地在端点烧毁。器件过载、烧毁、爆裂和断路器跳闸有各自的声音反馈。

触电造成每秒至多一次伤害，范围由实际线位判断，附带 15 刻轻微迟缓。地面放电点附近有局部地面危险区，水中范围更宽；创造和旁观模式免疫。尚不建立现实土壤电阻率场、人体频率响应或个人防护器材认证模型。

所有新放电音效是 22050 Hz 单声道 Ogg：3 个随机击穿变体、绝缘嘶响、熔断、跳闸、器件烧毁、爆裂。通过原版声音 API 从故障的具体坐标播放，有距离衰减。原有 15 段机械音效保留，共 23 段原创采样。客户端按维度清理效果，限制短期可见事件数量以避免大量故障造成渲染和声音风暴；不限制可建设的线路总数。

## 水槽与管道

水槽、透明管和核电冷却池使用 Fabric 流体渲染接口取得原版水的动画图集与生物群系颜色。贴图也随资源包替换；透明材质、面向不同方向的明暗和储量对应的高度参与容器渲染。它们只是储液模型，不会向世界放置水方块。铁皮管继续遮蔽内部水。

水泵保持 24 V、2.4 W、最高 50 mB/刻，即每秒 1 桶。泵后侧可以直接接原版水体，也可接存水槽；前侧接水管和目标槽。泵先按实际功率确定流量，再从同一个水域的账本提取，不会因增加泵而复制水。

有限水域的所有泵共享累计量：每个水方块按 1000 mB 计，累计抽完当前最高水层的总量后，同时移除整层，再处理下一层。中间不会逐格挖出小孔；整层移除先暂缓邻居更新，再统一通知，防止操作中途被原版无限水立即补回。进水口露出水面就会停止，建议把取水口设在底部。

已验证的连通水层达到 **1024 格**时视为大型可再生水体，不减少水位。多个泵共享有限水体时，下降速度与总抽水量对应。账本随世界保存，退出、重载不会清掉尚未抽完一层的用量。

只读取已加载水域；遇到未加载边界会暂停，避免把湖泊的一半当成全部。单次搜索预算 32768 个水方块，超出预算而尚未确认可再生面积时暂停。本版取水对象为原版水方块，不抽含水方块，不支持其他模组流体。原版流入、新倒水和玩家改造仍会改变实际水域。

## 模型和材料

- 核电保留 30×30 建造结构。增加安全壳竖向加强筋与分段带、人员检修门和台阶、管路穿口与阀轮、冷却塔底部百叶和环形立柱、爬梯、汽轮机大厅桁架、桥式吊装梁、检修面板、通风口、变压设施及接管。
- 火电增加耐火砖炉膛、灰门和紧固件、带支撑的检修平台、爬梯、泄压管、阀轮、烟囱抱箍及机组面板。大面材质按格分铺，修复大面积拉伸问题。
- 风机取消塔顶方形服务盒，圆锥塔筒连续接到机舱；底部出线座改为圆角筒式外壳和绝缘出线嘴。现有 OUT 接点坐标保留，升级后原来的线仍对应同一端口。
- 11 类材料细化为 128×128，区分混凝土接缝、钢板搭接、铆钉、通风百叶、格栅、炉砖、管道和检修门，避免所有设备套同一种机箱贴图。
- 多方块碰撞继续由同一几何数据生成。旧机组会补建新增细节所需的空气碰撞格，保留燃料、水槽及原始结构；占用处不会被强行替换，需要腾出空间。

## 矮型插排

物品 ID：`electron:low_profile_socket`。本体约 3/16 格，接点高度接近现有小型电路。A/B 两条独立母线，各四个接点，铜导通、电阻参与求解；它不生成电能，也不把红石与电互相转换。

无序合成：1 铜锭 + 1 石英 + 1 铁粒 → 1 矮型双母线插排。静态额定信息在物品提示中；生存中的实测读数仍通过万用表取得。

## 演示与验收

新地图火电泵从玻璃围住的原版水域取水；核电保留独立供水槽对照。悬线演示的风机底座位于 `(60,65,51)`，默认断开，潜行右键启停。护栏外可观察悬线与附近铁块间放电。自由实验台 `(41,66,57)` 有矮型插排。

验证包含共享抽水、整层下降、保存与重载、原版再生更新、能量约束、实际击穿面、低压不误放电、真实闪光自动清除、精确坐标数据和插排隔离。地图生成及重载验收均接通悬线展台 40 刻、确认漏电电流，再关闭供电保存。模型和电弧预览来自实际几何数据，不是游戏截图；客户端光影画面与混音最终效果仍需实际游玩确认。
