# Electron: Circuit Foundry — PCB 工坊与联锁 v10

适用版本：0.6.0-alpha.1，Fabric 1.21.1 / Java 21。本文记录已经落地的本阶段玩法，历史设计中的未实现器件不视为发行内容。独立计算器不参与本系统。

## 玩法闭环

发电与配电 → 24 V 制造工坊 → 设计并加工 PCB → 5 V 板上逻辑 → 继电器／MOSFET → 原有电机、照明、水泵等负载。制造、充电、输出均计入真实支路功率；电压不代替电能。

精密工作台采用俯视防静电工作垫。拖放零件编辑设计，拖动实际物品填右侧槽；加工中的材料锁定，底部漏斗只抽出成品。设计配件托盘用于选型，制作时才根据实际清单扣料。界面只显示规格、状态、进度和材料数量，实时电压／电流仍通过万用表读取。

## 板型与编辑

- 最大16×12个设计格，尺寸可选16×12、14×10、12×8、10×8；最多16个微型元件。
- 裁形工具可切边、挖缺口、做安装孔。禁止切断基板使其分成孤岛，禁止切掉端子、现有走线和元件。
- 元件拖放、移动，R 或板面右键旋转90度。每个配件占3×3设计格，禁止重叠。移动器件保留原铜线，需自行重新接线。
- 铜线工具两次点击端点布线，默认先横后竖，Shift改为先竖后横。右键结束连续布线。同层铜线交叉会连接；本版没有板内跨线桥、双面铜和过孔。
- 板边六个外部逻辑端口：VCC、GND、A、B、Y、Z。底座上的实际端子随方块朝向转动，板形尺寸改变不会改变外部端口顺序。
- 删除工具删除命中元件及当前格相邻铜段。板缩小时如果已有内容越界则拒绝，不会静默删除设计。
- “非门示例”载入可以实际运行的参考板；“读取板型”读取成品沉金板上的原设计。沉金后的铜线、板型和配件清单不能免费重写。

## 制造工序

工作台和五台工序机额定24 V，工作范围18–30 V，接正负两根电缆。PCB 在底座中使用5 V，不能直接接24 V加工电源。加工停电暂停、输出满暂停，状态与已付出的加工能量保存进存档。

| 工位 | 投入 | 产出 | 额定负载／工序能量 |
| --- | --- | --- | --- |
| 精密电子工作台（光绘） | 1感光胶片＋1黑色染料＋设计 | 带设计的光绘掩膜 | 24 W；40＋12×配件数＋0.5×铜段数 J |
| 紫外曝光机 | 1覆铜板＋1对应掩膜 | 曝光板 | 12 W／80 J |
| PCB 钻孔机 | 1曝光板＋1微钻头 | 钻孔板 | 18 W／160 J |
| PCB 蚀刻清洗机 | 1钻孔板＋1蚀刻药液盒 | 蚀刻板＋1废药液盒 | 16 W／200 J |
| 阻焊涂覆固化机 | 1蚀刻板＋1阻焊树脂 | 阻焊板 | 12 W／120 J |
| 沉金处理机 | 1阻焊板＋1沉金药液盒 | 沉金板＋1废药液盒 | 24 W／300 J |
| 精密电子工作台（焊接） | 1沉金板＋配件清单＋焊料 | 已焊接 PCB | 24 W；同光绘公式 |

焊料消耗为全部配件引脚数除以8向上取整。电阻和LED各2脚；逻辑门5脚（VCC、GND、A、B、Y）。非门B脚不参与逻辑运算。

所有中间板和掩膜保留同一份板型、铜线、配件与转向数据。工序没有随机换版；不同设计不会混入同一输出堆。药液是游戏内抽象耗材，不模拟真实化学反应、工业配比或化学安全过程。微钻头在本阶段按一次耗材处理。

## 实际电路

可安装微型1 kΩ／10 kΩ电阻、LED、NOT、AND、OR、XOR、NAND。板上铜段建立实际网络，电阻和LED参与同一个直流求解器；逻辑门使用5 V供电、2刻传播延迟和有限输出驱动。欠压、浮空输入、相互争用都可能导致非确定或无效逻辑，不能把图形上的连线当成虚拟无限驱动力。

基板逻辑供电4.5–5.5 V，门输出含100 Ω等效驱动电阻。电阻额定0.125 W，LED仍需外部或板上限流；反接和过流会积累热损伤。烧坏的板转为废料，空底座可重新装入新板，不可通过拔插恢复烧坏的配件。对大型负载使用电磁继电器／MOSFET和独立负载电源，接法沿用主线规则。

持已焊接板右键空底座安装，潜行空手右键取出。世界里显示实际板形、走线、封装、焊点和点亮的微型LED。板上小配件无需各占一格方块。红石与电学保持隔离。

## 联锁与备用照明

| 设施 | 用途与规则 |
| --- | --- |
| 电动水位开关 | 5 V供电；检测直接相邻的一个专用水槽。模式0低于25%闭合补水、达到75%断开；模式1／2为25%／75%水位信号，含5%回差。接多个水槽、缺槽、断电或损坏时开路。 |
| 电动温度联锁器 | 5 V供电；检测直接相邻的一个受支持电力机组，60／90／120°C预设，5°C复位回差。超过阈值断开，目标损坏、缺失或多个目标也开路。 |
| 两种传感器触点 | 供电脚和COM／NO触点隔离，触点额定30 V／2 A；不产生电压。用于切断负载或驱动继电器，不直接开断高压电站。 |
| 蓄电应急灯 | 24 V额定，1.2 W照明、最高6 W充电、90%充电效率、200 J容量；新制为空。输入有效时15级方块光照，失电后消耗储能保持11级，空电量熄灭。拆装保留已充电能。 |

## 模型与性能

PCB 工坊是台式机器，单个方块内使用多个细分结构；单方块不代表单一立方体模型。精密台有四脚、抽屉、工作垫、夹具、放大镜、烙铁架和配件槽。钻床有导轨、压板、主轴；蚀刻有板架、液面、循环管和观察窗；沉金有三个独立槽、横梁、升降夹具。各机器有独立外观，接线口放到后侧矮接线盒，实际线端与转向同步。

旧四台加工机保留端子位置，把长柱收进有门缝、百叶、手柄、铭牌的接线柜，防止旧档电线悬空失联。新设备壳体使用256像素材质，微型封装使用128像素材质；拉丝金属、烤漆、橡胶、玻璃和镀金分别处理。机壳和小装饰表面避免共面闪烁。

静态模型由 Minecraft 烘焙，钻头和沉金夹具使用独立烘焙动件。碰撞仅保留主要机架、槽体和接线盒，不逐螺丝建碰撞；形状缓存按机器和朝向复用。板铜网编译缓存、工作台同步格点缓存、客户端设计解码缓存减少重复分配。没有以模型精细度或缓存推断实测帧率。

## 地图与阶段边界

新工坊位于南侧z=100..136。六个制造台面使用风电＋24 V变电供电；第二排包含已焊接非门控制LED、水位触点控制工坊灯，以及充好电的应急灯。材料箱里有带设计的各阶段板，便于分步骤实验。各台机器预装的是独立演示批次，没有自动跨机物流。

尚未实现：双层／多层板、过孔、逐焊点手动焊枪、可编程MCU、板上升降压芯片、完整工业化学和机械传送线。未来开发板模拟游戏内的编程与I/O，不兼容真实STM32固件。
