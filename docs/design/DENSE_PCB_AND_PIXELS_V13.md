# Electron: Circuit Foundry — 高密度 PCB、像素屏与单板计算器

对应版本：0.8.0-alpha.1。Fabric 1.21.1 / Java 21。本文及游戏内工程手册优先于 v10–v12 的单层、16 元件与多板计算器说明。

## 单张 PCB 计算器

样板只有一张 PCB：80×88 网格、四层铜线、58 个元件。其中包括两个 0–9 十进制拨盘、一个加减开关、52 个基本逻辑门、负号显示条和两个数码显示模块。底座占 3×4 格，由一个主插座和 11 个底座扩展片提供支撑。

52 个门由 XOR、AND、OR、NOT 组成。原来的半加器封装在这个示例中拆为独立 XOR 与 AND，进位、补码加减、绝对值和十进制修正都经过实际焊盘、铜线、过孔及供电轨。运行时没有计算表达式、加减操作数或直接填写结果的控制器。示例生成器只生成可修改的布线数据，运行由普通 PCB 求解器承担。

空手点击板上 A/B 拨盘加一，潜行点击减一；第三个输入开关关闭为加法、开启为减法，结果范围 −9…18。门有两游戏刻传播延迟，请等电路稳定。断电、支撑不完整、错误连线或输出短路都会影响工作。

教学地图的新计算器主插座位于 `(54,66,145)`，初始为 9+7=16。板外只接小型导线供电；板内全是铜线。另设在 `(54,66,153)` 的 PCB 是独立的像素/RGB 练习，不参与计算器运算。

## 设计容量与操作

- 默认网格 32×24，最大 128×96，最多 256 个配件，可选择一至四层铜线。元件保留 3×3 的焊盘网格，在更密的基板上显示得更小。
- 元件盘支持搜索、分类及滚轮翻页，拖动放置和移动，R 旋转，Delete 删除，Ctrl+Z/Y 撤销/重做。
- 滚轮以鼠标为中心缩放，范围 1–40 屏幕像素/格；中键或空格拖动平移，“适应”显示整板。
- 布线工具连续点击节点，Shift 改变折线的先后方向。铜线按当前铜层绘制，同层交叉连接；异层交叉绝缘。
- 过孔为镀铜贯穿孔，将同一位置的各铜层连接。手动放置过孔需要多层板。自动示例在焊盘内预留贯穿孔，避免后续线路封堵焊盘出口。
- 接口工具选择 VCC/GND/A/B/Y/Z 后，可把相应接触焊盘放在任意可用板边位置。插座本身仍是六个固定外部端子，映射到这些可移动板边接触点。
- 改板型或移动器件不会替你重接已经铺好的铜线；请检查受影响的端口和焊盘。
- 普通点击“示例”为反相器，Shift+点击为半加器，Ctrl+点击为像素练习板。“单板计算器”加载完整可编辑样板。

旧 v2 PCB 数据中的 16 列坐标会逐点迁移到新格式，保留原板尺寸、铜线、器件方向及连接关系。已有焊接站输出槽也单独迁移，不会被新增元件槽吞掉。主线不引用、调用或依赖 `calculator/` 中的独立红石计算器。

## 新增与补齐的元件

| 类别 | 元件与功能 |
| --- | --- |
| 完整基础门 | AND、OR、NOT、XOR、NAND、NOR、XNOR、BUFFER |
| 组合逻辑 | 半加器、二选一选择器、三态缓冲器 |
| 时序 | D 触发器、时钟振荡器 |
| 板上输入 | 0–9 十进制拨盘、拨动开关 |
| 显示 | 数码屏、负号条、独立 RGB 灯珠、8×8 像素屏 |
| 基础器件 | 1 kΩ / 10 kΩ 电阻、LED |

新增配件各有三维物品模型与配方。器件插到 PCB 底座后仍可见，LED、RGB、数码屏和像素屏显示实际电气状态。基座端子改为低矮接触片。

数字器件的供电范围为 4.5–5.5 V，每路逻辑输出额定 20 mA；输出切换真实供电轨，不产生电能。普通门有约 0.5 mA 静态负载，数码屏约 5 mA。RGB 约 1 mA 基础负载，每个亮色增加 3 mA；像素模块约 2 mA 基础负载，每个亮点增加 0.3 mA，均以 5 V 计。

D 触发器在 CLK 上升沿采样 D。三态缓冲器 EN=0 时输出高阻，EN=1 时传 A。MUX 的 SEL=0 选 A、SEL=1 选 B。时钟默认 1 Hz，点击切换 5、10、15、20、25 游戏刻半周期。寄存状态与帧缓存是易失的；机械输入控件设置保存在世界中。红石不能直接供电或驱动这些电路。

## 大板的材料、电力与支撑

令 `U=ceil(width*height/768)`，`M=U*layers`。最大板的 M 为 64，可在原有加工机中付费处理。

| 工序 | 消耗 | 输入电能 |
| --- | --- | --- |
| 光绘 | M 光绘膜、M 黑色染料 | `40M + 12×元件数 + 0.5×铜线边数 + 4×过孔数 J` |
| 曝光 | M 覆铜基板、1 份带图样底片 | `80M + 2×过孔数 J` |
| 钻孔 | 1 曝光板、M 微型钻头 | `160M + 2×过孔数 J` |
| 蚀刻 | 1 钻孔板、M 蚀刻剂筒 | `200M + 2×过孔数 J`；产 M 废药液筒 |
| 阻焊 | 1 蚀刻板、M 阻焊树脂 | `120M + 2×过孔数 J` |
| 沉金 | 1 阻焊板、M 沉金药液筒 | `300M + 2×过孔数 J`；产 M 废药液筒 |
| 焊接装配 | 1 同图样沉金板、实际元件、每 32 引脚一份焊料 | 同光绘能量公式 |

加工功率保持现有机器的实际输入能力，板更大或铜层更多会增加总耗能与时间，不会免费加速。钻孔、蚀刻等阶段不足量的耗材不会启动处理。切掉轮廓空白不返还基材成本。

装配支持分批补充超过一组的同类元件。已投入材料暂存在当前作业中并写入存档；缺料时等待补料。大型工序超过 10000 J 的已付费进度同样保留，断电时暂停。取消作业归还材料，已完成的作业不再退款。材料盘分三页显示，底部可用漏斗抽取成品。

底座宽为 `ceil(width/32)`，长为 `ceil(height/24)`。玩家须实际摆放扩展片，不能把大板悬空塞进单格插座。多格板仅支持水平放置；单格旧板继续保留原来的安装方向。支撑被拆掉时电路停机，补回后恢复。

## 可逐像素控制的显示屏

微型模块为 8×8，外部像素面板每块也为 8×8；外部面板在同一平面、相同朝向拼成矩形后共用帧缓存。2×2 面板为 16×16，共 256 位。最多 256 块面板，非矩形组合各自显示。

六个引脚为 VCC、GND、DATA、CLK、LATCH、CLEAR。先稳定 DATA，CLK 从低到高移入一位。按整幅画面从左上到右下逐行发送；最后 LATCH 上升沿提交整帧。CLEAR=1 清空移位寄存器和显示画面，断电也清空。没有字库限制，也不会替用户自动画数字、执行算式。

教学练习板的四个开关从左到右对应 DATA、CLK、LATCH、CLEAR。板上的 RGB 显示前三路信号，板内像素屏和外部面板接受相同串行数据。地图导出与重载时以真实开关脉冲写满画面；正常游玩不保留这个开发期脉冲程序。

## 数学蘑菇云

效果使用随时间连续变化的解析几何采样，不摆放实体方块，也不进行核反应或武器物理仿真：

- 云柱高度 `H(t)=4+40(1-exp(-t/90))`；主半径 `R(t)=2+21(1-exp(-t/90))`。
- 云冠按环面参数式 `r=0.66R+0.26R cos(phi)`、`y=H+0.1872R sin(phi)`，再用方位角展开到 x/z，`phi` 随时间平滑变化，并随方位角错开采样，避免出现一层层的水平烟环。
- 环缘叠加低幅连续正弦扰动；顶部用等面积极坐标采样的扁椭球填充，避免只有一个空心圈。
- 烟柱底部扩张、颈部收窄；地面尘环按独立的指数增长半径扩散。
- 每次最多 168 个烟团，约 20 秒淡出；保留发生点的闪光、碎片和定位爆炸声。

预览来自实际 Java 采样点与游戏材质。烟云视觉尺寸不扩大原有局部事故破坏半径。

模型、贴图、双语言及真实存档均有自动审计。预览为离线渲染；没有使用 Computer Use，也没有把离线预览称作客户端逐项视觉验收或帧率实测。
