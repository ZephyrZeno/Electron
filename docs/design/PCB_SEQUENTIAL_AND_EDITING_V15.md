# 0.8.2-alpha.1：时序 PCB 与区域编辑

本版扩展 Minecraft 主线 Electron: Circuit Foundry 的 PCB 制作与数字电路。独立原版红石计算器模组、UE 游戏工程保持独立。

## 四种新增微型器件

所有新器件额定 5 V，数字功能使用 4.5–5.5 V 的有效供电范围。VCC 和 GND 必须通过铜线接入实际电源；时钟、逻辑、显示和输出负载会消耗电能。以下引脚顺序与编辑器悬停提示一致，Q0 是最低位。

| 器件与 ID | 引脚顺序 | 行为 |
| --- | --- | --- |
| T 触发器 `smd_tff` | VCC、GND、T、CLK、RESET、Q | RESET 高有效异步清零；正常运行时，CLK 上升沿遇到 T=1 翻转 Q，T=0 保持 |
| SR 锁存器 `smd_sr_latch` | VCC、GND、S、R、Q | S=1/R=0 置位，S=0/R=1 复位，S=0/R=0 保持；S=R=1 为未知状态 |
| 4 位计数器 `smd_counter4` | VCC、GND、CLK、RESET、Q0、Q1、Q2、Q3 | RESET 高有效异步清零；每次 CLK 的确定 0→1 上升沿增加一，15 后回到 0 |
| 4 位移位寄存器 `smd_shift4` | VCC、GND、D、CLK、Q0、Q1、Q2、Q3 | CLK 上升沿把 D 写入 Q0，原 Q0→Q1、Q1→Q2、Q2→Q3；连续输入四个已知位可以建立完整状态 |

时序器件上电记忆是 **X（未知）**。T 触发器、计数器需要复位；SR 锁存器需要明确的置位或复位；移位寄存器需要实际写入。保持高电平的时钟不等于重复上升沿，刚接通电源时已经为高的 CLK 也不制造一次虚假计数。未知时钟或输入按不确定状态传播，不自动当作 0。

断电后输出进入 **Z（高阻）**，易失记忆丢失；再次供电需要重新初始化。状态和前一次时钟电平随当前板卡保存，正常存档重载不会凭空增加一个边沿，也不会把一次已经付费的时钟事件重复执行。输出保留有限驱动阻抗和两游戏刻传播延迟，仍受实际负载、欠压、过载和损坏规则约束。

这套实现是游戏内的离散电路仿真：由实际铜网的电压、时钟边沿和存储状态决定结果。它不宣称精确复刻某颗现实芯片的亚稳态、纳秒时序或晶体管内部结构。

## 制作成本与外观

四种配方都是普通工作台无序合成，每次仅得到一个器件。基础门、D 触发器、焊料、铜箔沿用现有制作路线；完成芯片合成后，把它焊到 PCB 上仍需支付 PCB 加工、装配材料和电能。

| 产物 | 实际消耗 |
| --- | --- |
| 1 个 T 触发器 | 1 个 D 触发器＋1 个 XOR＋1 个 AND＋1 份焊料＋1 份铜箔 |
| 1 个 SR 锁存器 | 2 个 NOR＋1 份焊料＋1 份铜箔 |
| 1 个 4 位计数器 | 4 个 T 触发器＋2 个 AND＋1 个 NOT＋1 份焊料＋1 份铜箔，共 9 格材料 |
| 1 个 4 位移位寄存器 | 4 个 D 触发器＋1 个 AND＋1 份焊料＋1 份铜箔 |

物品采用独立三维封装：分层模塑壳体、实体方向凹口、引脚 1 标记以及分开的银色折弯引脚。T、双稳态回路、计数台阶、移位箭头分别作为简洁的几何顶标；不添加电压铭牌。T/SR/计数/移位封装分别有 6/5/8/8 个引脚，背包与手持使用立体模型。

资源脚本 `tools/generate_pcb_sequential_assets.py` 只生成这四种模型、配方及解锁进度，复用已有材质；`--check` 只读检查结果一致性、引脚数、纹理引用、模型边界和叠面裁剪。不会重新生成旧工作台、机组或已修复的模型。

## 设计站操作

元件盘分为六类：全部元件、基础元件、组合逻辑、时序与存储、灯与显示、输入与时钟。部分器件可出现在多个分类，例如时钟同时属于时序与输入。每页显示八个器件，提供立体图标和短代码；悬停查看完整名称。搜索当前语言名称或类型名称（例如 `COUNTER4`），点击左右翻页按钮，或在元件盘内滚动鼠标翻页。搜索及分类变化会回到第一页。

| 操作 | 方法 |
| --- | --- |
| 放置元件 | 从左侧元件盘拖到板上，合法位置才接受放置 |
| 移动单个元件 | 移动工具下拖动板上的元件；R 旋转，拖动时右键也可旋转 |
| 平移视图 | 移动工具下拖动空白处；或中键、空格＋左键、下方“平移”工具 |
| 缩放 | 在画布内滚轮缩放，保持鼠标所指位置；Shift＋滚轮上下平移 |
| 查看整板 | F 或下方“整板”按钮 |
| 框选模块 | 选择“框选”工具后左键拖动；或在移动工具下 Shift＋左键拖动 |
| 全选 | Ctrl+A 选中整块板的矩形范围 |
| 复制模块 | 框选后 Ctrl+C，再 Ctrl+V；移动预览后点击目标位置 |
| 移动模块 | 框选后 Ctrl+X，再 Ctrl+V；点击目标位置提交移动 |
| 使用按钮复制／移动 | 框选后点击上方“复制”或“移动”，直接进入放置预览 |
| 删除 | 框选后按 Delete 或点区域删除；也可删除当前选中的单个元件 |
| 撤销／重做 | Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做；上方按钮等效 |
| 取消 | Esc 取消当前选区、拖放或预览；右键取消正在连接的铜线或粘贴预览 |

搜索框获得焦点时，文字输入和文本编辑快捷键由搜索框处理。单独旋转元件不会自动改布它周围的铜线；整组旋转暂未加入。

区域操作覆盖 **所有铜层**：完全处于框内的元件、两个端点都在框内的铜线段和框内过孔一起参与。只被框住一部分的器件不会移动。板形、切除区域、六个外部接口保持原位。

**跨越选区边界的铜线段始终留在原位置**，包括搬移或删除时。界面显示边界线数量；移动模块后，应根据新焊盘位置重新连接这些线路。粘贴后的铜线仍遵循普通连接规则，同层重叠会成为同一个网络，不自动生成隔离层。

Ctrl+X 只准备移动，不会立即挖掉原区域；直到目标位置通过整张板校验后，服务器才一次性提交移动。越界、器件重叠或落入已裁去区域时，预览显示为无效，原设计保持不变。

剪贴内容只用于 **当前布局的当前版本**。复制后如果继续改线、改变板型、撤销、读取另一张板或布局被其他玩家更新，需要重新框选复制。成功粘贴一次会清除本次剪贴状态；不支持跨板／跨界面的系统剪贴板导入。区域操作保留服务器版本校验和撤销记录。

板外空白处不再产生过孔、擦线或接口移动操作；服务端也在坐标编码前校验真实行列和铜层，避免越界点击映射到板内另一处。元件拖到板边时，非法位置的预览焊盘留在本地位置，不跳到另一行。多人修改使布局版本变化时，会取消旧的拖放状态；材料分页作为视图操作独立处理，不受设计版本的暂时延迟影响。

设计站可编辑最多 128×96、256 个器件、四层铜线的板卡。层间连接使用显式贯穿过孔；PCB 越大、层数越多，加工耗材和电能越多，大板需要对应面积的实体底座。焊接装配站只能查看和装配实际加工出的铜线图，不能修改裸板设计。

## 单板计数器练习

在新教学地图的数字教学箱 **`(59,66,158)`** 取得样板。箱子原有物品保留；以下槽位按程序零起算，槽位 13 对应玩家从左上开始数的第 14 格。

| 槽位 | 内容 |
| --- | --- |
| 13 | 已装配的计数器 PCB |
| 14 | 同布局的沉金裸板，可用于焊接练习 |
| 15–18 | T 触发器、SR 锁存器、4 位计数器、4 位移位寄存器，各 16 个 |

该板为 **32×24、两层**，一个 PCB 底座即可支撑。板上包含时钟、RESET 开关、4 位计数器、一个数码显示器，以及 1 kΩ 电阻与 LED。所有电源和信号都由 `PcbRouter.route` 生成的可编辑铜线和过孔连接；显示器只译码，不代替计数器计算。

操作流程：

1. 放置 PCB 底座，持成品板右键装入，把实际 5 V 电源的正负极接到 VCC 和 GND。
2. 上电后计数器尚未初始化。空手点击板上 RESET 开关置为 1，等待传播后显示 0；再点击一次切回 0。
3. 板载时钟随后驱动计数器循环 0–15。单个数码器件显示十六进制 **0、1、…、9、A、b、C、d、E、F**；七段字形中的 b/d 表示 B/D，不是十进制的两位显示。
4. LED 通过 1 kΩ 限流显示 Q0，计数奇偶变化时切换明暗。外部 Y、Z 分别连接 Q0、Q1，可接入其他兼容的 5 V 电路。
5. 再次将 RESET 置 1 可保持清零，切回 0 后重新计数。断电后显示和 LED 熄灭，恢复供电后需要重新复位。

外部 A、B 分别引出 CLK、RESET，默认样板已由板载器件驱动，不必额外接线。需要外部时钟或复位时，应先在设计站修改对应铜线和输入器件，再按加工流程重新制作。

默认时钟半周期为 10 游戏刻，即完整周期 20 刻；空手点击时钟可切换 5/10/15/20/25 刻半周期，潜行点击反向切换。实际计数速度受服务器游戏刻速率影响。

也可在设计站用示例切换按钮选中计数器，再加载其完整布局，修改后制作自己的板卡。数字箱提供的沉金裸板需要按当前布局补齐对应元件和焊料，再给装配站供电完成焊接。

新四种器件集中放入原数字箱，PCB 加工区原有两箱与槽位保持不变。数字箱由 13 叠增至 19 叠；整张教学地图仍是 24 箱、149 个器件、29 块告示牌，总物品叠数为 397。

## 验证范围

`PcbCounterExampleTest` 对实际布线与 DC 网络运行完整 16 值计数循环，检查上电 X、复位、回绕、电源负载和断电。`PcbCounterExampleTests` 在 Minecraft 世界中通过手摇电源、表面导线和 PCB 底座验证同一张教学板。区域编辑的边界、整组校验与状态过期行为由专门测试覆盖；界面检查包括实际客户端截图与缩放后输入坐标。

这些检查验证游戏内实现，不能据此把额定值或合成配方当作现实电子设计和半导体制造参数。
