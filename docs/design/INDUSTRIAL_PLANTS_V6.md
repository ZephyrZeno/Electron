# 工业机组与供水 v6

对应主线 **0.5.0-alpha.1**，Minecraft 1.21.1 / Fabric / Java 21。本文记录已经实现的规则。三层电路划分沿用 v3；PCB 制板、焊接、可编程开发板仍未实现。主线与独立计算器没有代码依赖。

## 从零件到电站

制作大型机组装配台，在连续实心基础上放置。它占 **3×2 格**，各格共用原点的物品栏和界面。放入材料，在右侧选择部件，再按“装配所选部件”；缺料或成品槽不兼容时不会扣材料。拆任意一格会返回一个装配台和其中材料。

| 部件 | 每件消耗 |
| --- | --- |
| 锅炉 | 铁块×4、铜块×2、继电器×2、1 kΩ 电阻×2 |
| 汽轮机 | 铁块×3、铁锭×12、传动轴×2、电机×1 |
| 发电机 | 铜块×4、铁块×2、电机×2、二极管×4 |
| 冷凝器 | 铜块×3、铁皮水管×8、电容×2、继电器×1 |
| 机组控制柜 | MOSFET×4、继电器×4、1 kΩ 电阻×4、LED×4、铁锭×8 |
| 反应堆压力容器 | 屏蔽机壳×16、铁块×8、冷凝器×2、控制柜×1 |
| 控制棒驱动 | 铁块×4、电机×4、继电器×4、控制柜×1 |
| 安全阀 | 铁锭×8、继电器×2、100 Ω 电阻×2、铁皮水管×2 |

火电控制器配方：控制柜部件、锅炉部件、发电机部件、机组机壳各一件。核电控制器配方：控制柜部件、压力容器部件、控制棒驱动部件、屏蔽机壳各一件。控制器之外，场地上的各实体部件仍须另外制作。

所有机组、变电柜、塔架完成结构后，约 **10 游戏刻**自动成型，不需要扳手。原材料被记录并并入整体模型，每个占用格有对应碰撞。普通容器、物品栏和已有线路不会被静默吞掉。拆掉结构会恢复其余材料；扳手主动解除后暂停自动成型，再次点击扳手恢复。

**升级旧世界：**旧版小型火电、核电、使用桁架的风机需要按新结构重建。先用扳手拆解旧结构、保留材料，再搭新设施。旧世界不会被教学地图覆盖。

## 火电：7×7 自建机组

控制器在基础前沿中央，端子朝上。以下坐标是控制器的局部坐标：右为 +X、后为 −Z、上为 +Y；坐标随控制器旋转。基础在 Y=−1，平滑石铺满 X=−3…3、Z=−6…0，上方至少留 8 格净空。

| 实体部件 | 相对坐标 |
| --- | --- |
| 锅炉 | (0,0,−4) |
| 汽轮机 | (2,0,−3) |
| 发电机 | (2,0,−1) |
| 冷凝器 | (−2,0,−4) |
| 控制柜 | (0,0,−1) |
| 安全阀 | (0,1,−4) |
| 锅炉补水槽 | (−2,0,−1) |

模型包含锅炉、炉膛、烟囱、汽轮机、发电机、冷凝散热片、带法兰管线和检修栏杆。给专用水槽补水，再给控制器加煤或木炭。每份燃料提供 16 kJ 游戏热能，按 35% 转换效率燃烧；缓存满时仍会烧掉运行所需燃料，不能积累无限能量。输出 **11 kV / 最多120 W**，接匹配的 11 kV→240 V 变电站，再按需降至24 V。启动至少250 mB，运行/余热冷却每刻消耗4 mB。

## 水电与风电

水电控制器放在平滑石上，涡轮端在局部坐标 (0,0,−1)，只需该端接触**流动的水**。静止水源不能驱动；不再要求旧版固定落差/尾水结构。模型包含蓝色涡壳、轴和散热电机。输出6.6 kV，最多160 W；这是游戏化水流判定，没有完整流体力学或水头功率计算。

风电先放**风机底部接线柜**，上面堆6–63节专用白色塔筒，最上面放风机控制器。实体基础在底柜下方。留出直径约10格的叶片回转范围与机舱顶部空间，自动形成上细下粗的圆锥塔筒、法兰、机舱和三片转动叶片。风机输出经塔筒中的内部引下线传到底柜 **OUT+/OUT−**，顶部不提供接线点。输出240 V，功率受高度、天气和时间的游戏风速模型影响。输电塔继续使用独立钢制桁架与横担，不能代替白色风机塔筒。

## 核电：30×30 独立设施

基础在Y=−1，铺满X=−15…14、Z=−29…0，共900块平滑石。控制器在前沿，顶部留21格净空。将屏蔽机壳沿X=−8…2、Z=−25…−15的四边围成三格高的方环，共120块。

| 实体部件 | 相对坐标 |
| --- | --- |
| 压力容器 | (−3,0,−20) |
| 控制棒驱动 | (−3,1,−20) |
| 安全阀 | (−3,3,−20) |
| 汽轮机×2 | (7,0,−7)、(10,0,−7) |
| 发电机 | (7,0,−3) |
| 冷凝器 | (6,0,−15) |
| 控制柜 | (−8,0,−3) |
| 核电冷却水槽 | (−14,0,−5) |

最后一个部件完成后形成安全壳和穹顶、冷却塔、汽轮机厂房、控制室、独立水池、管路和围栏。水槽的服务口保留为真实可操作方块，大水池水位随该槽储量变化。加入燃料棒，输出**24 kV / 最多400 W**，通过24 kV→240 V变电站供电。

燃料棒提供200 kJ游戏热能，30%转换效率，耗尽后取出乏燃料棒才能再装填。启动至少1000 mB，运行或余热冷却每刻消耗20 mB。温度与余热保存在世界存档中；失水停止发电，热态缺水会跳闸和报警。停堆后仍需冷却，持续失冷且温度超过事故阈值会损坏机组，并发生有范围限制的压力爆炸。热电/核电压力事故的爆炸强度分别为3/5，影响附近方块；事故清空燃料和余热，避免同一存能重复爆炸。

现实参考采用燃料加热、蒸汽带动机组、冷凝与冷却的分工，参见[美国能源部核电原理](https://www.energy.gov/ne/articles/nuclear-101-how-does-nuclear-reactor-work)。游戏里的功率、水耗、场地尺度、温度阈值是玩法参数；没有核武器、真实辐射剂量或核反应计算。

## 有限水量与电动供水

| 对象 | 规则 |
| --- | --- |
| 锅炉补水槽 | 16,000 mB；独立金属水槽和观察窗 |
| 核电冷却水槽 | 256,000 mB；不同机壳，成型时连接大水池显示 |
| 铁皮/透明水管、截止阀 | 每格250 mB真实管内水量；六面连接，右键阀门开关 |
| 电动水泵 | 额定24 V / 2.4 W；18–30 V工作，最大1 L/s |
| 水桶 | 装入/取出1000 mB，消耗/返回对应水桶物品 |

水泵后侧从水槽或原版水源格吸水，前侧接管道/目标水槽。实际消耗源方块或源槽储水，先灌满沿路管道再送入目的槽；找不到有空间的目的槽、断电、堵阀时不抽水。单次连通搜索最多256格。多个泵顺序扣同一份水，不复制流体。拆管/拆槽会丢失内部水。

透明管内显示蓝色流体与移动流标；水槽有实际水位。铁皮管保留金属表面和法兰。流体网络目前仅有水，暂未独立求解蒸汽、压强、沸腾、管阻和泄漏。工业机组的蒸汽循环用有限燃料、供水和余热状态近似。

教学地图的泵由本机组变电输出供电。实际长期设施可以加独立备用供电维持停机后的冷却；演示中的补给水槽有限，需玩家补水或接入可再生水源。

## 双端悬线、扩展接线与引雷

小型导线和粗电缆都允许**纯垂直悬线**。两端接器件、螺钉端子或穿墙口的真实接点，必须上下对齐，不能悬空自由节点收尾。实际长度最多64格，包含端子引出段，按1/16格扣料。中间不能碰实体或流体；拆任一端即断线、回收已付线材。跨未加载区块暂停，不凭空掉线。斜跨和横跨空中仍只允许完整输电塔间的电缆。

新增**电缆扩展接线座**：A1–A4、B1–B4两条隔离母线。用粗缆进线，再用细线接小器件；连接点仍按各自额定电流限制。粗缆在靠近端子的最后半格渐细，减少遮挡。

成型引雷装置可在水平64格范围内，截获原定落点低于塔尖的雷击；符合条件的多座塔随机选一座。一次真实雷击记录300 MV/30 kA瞬态峰值，最多回收3000 J，缓存上限4000 J，之后通过240 V输出级供电。同一实体的重复闪光只记一次，全世界持久化最近4096次记录。

此范围是游戏规则；[美国国家气象局对避雷针的说明](https://www.weather.gov/safety/lightning-rods)明确其作用是提供安全导电路径，并非吸引范围内全部闪电。风机外形参考[美国能源部风机结构说明](https://www.energy.gov/articles/how-wind-turbine-works)的管状塔筒、机舱和叶轮分工。

## 资源、声音与开发验证

本次增加18个方块，15段原创合成的单声道Ogg音效：细线接入、粗缆锁紧、剪线、端子安装、装配、成型、泵、阀、水槽注水、电机、风机、水轮机、汽轮机、失冷报警和压力爆裂。已有开关、逻辑门和烧毁反馈保留。字幕随中英语言切换，声音受游戏方块音量与距离控制。没有添加光影包。

`generate_industrial_assets.py`生成细部方块模型、64像素材质、配方和字幕，`generate_industrial_guide.py`生成双语教程。工程手册共24页、20张教程图，各有中英文版本。模型预览来自实际网格导出，不能代替客户端的光照、动画和声音试听验收。

Ogg样本随源码提交；通常重建资源无需音频依赖。需要重合成时，可用 `python -m pip install --target build/audio-tools numpy soundfile` 安装到忽略的构建目录，再运行资源脚本。不要把该依赖目录或生成的存档、发行包加入Git。

验收包含：原有电学测试、自动成型、拆解恢复、30×30基础、有限水量和断电泵、装配扣料、拆台掉落、垂直双端固定、雷击筛选与重复回收保护、缺水事故；教学地图从新世界生成，保存重载并再次验证机组、泵、物品箱与零掉落物。
