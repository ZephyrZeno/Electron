# 0.8.1-alpha.1：PCB 操作、手册与机组外观修复

本次仅修改 Minecraft 主线模组，不涉及独立计算器模组或 UE 游戏工程。

## PCB 设计站

- 选择／移动工具下，拖动空白板面或工作垫即可平移；元件仍可单独拖放。
- 下方增加独立“平移”工具和缩放按钮。在焊接装配站的只读视图中同样可以平移。
- 中键拖动、空格＋左键拖动在任何设计工具下可用，离开画布松开鼠标也会结束平移。
- 滚轮围绕鼠标指向的位置缩放；Shift＋滚轮上下平移，横向滚动支持左右平移。
- F／整板按钮恢复完整视图。改变游戏窗口大小或 GUI 比例保留缩放与偏移；读取尺寸不同的板型时适应新板。
- 屏幕缩放只在输入边界转换一次，网格只绘制当前可见区域。
- 画布裁剪按实际 GUI 坐标换算，放大后的铜线、焊盘和元件不会越界覆盖材料栏或背包。按钮使用同一套配色，长标签截短显示，避免自定义界面缩放导致文字消失。

## 工程手册

Minecraft 1.21.1 的 `Screen.render` 会再次调用 `renderBackground`。旧代码先画正文，再调用父类绘制按钮时把深色背景盖到正文上。本次将背景改为只在文章前画一次，父类的背景回调留空。

正文使用浅色卡片和深色文字，目录使用深色底与高亮当前章节；底部导航统一样式。教程图保持原始颜色，可点击放大。左右方向键翻章节，Page Up／Down 滚动正文，Home／End 定位文章首尾；翻页时目录会滚动到当前章节。

## 缺水提示

保留供水、温度、停机和事故规则。替换旧的硬切高频调频警报，使用 0.94 秒的双音提示，平滑起音和尾音，单声道由机组接线柜位置发出。

- 冷态空水槽不报警。
- 成型且未损坏的机组失去冷却，温度达到 45 时开始普通警示，每 400 游戏刻最多一次。
- 达到 100 时升级为严重警示，每 100 游戏刻最多一次；升级最多提前到距上次 40 刻。
- 补水或温度降至 38 后停止，短暂来回断水不会反复重触发。

## 模型与管道

核电站补齐主蒸汽总管、第二台汽轮机支路、冷却回水、辅助支路及固定燃料／乏燃料接口的封闭输送管。路径使用连续圆弯头，原料接口的位置与物流规则保持兼容。火电管道也改为有明确水平段、立管和弯头的连接。

工作台、PCB 底座、灯具、加工机与机组的静态模型移除完全埋藏的表面，对同平面叠面做保留 UV 的局部裁切。透明和镂空材质不作为遮挡物。大型机组的运行时网格对重复杆件去重，清除相邻筒段重复端盖和机壳叠面。静态网格继续缓存，不在每帧重复计算。

几何版本由 6 提升到 7：已有成型设施加载后尝试刷新碰撞体。新增管路的空间若被玩家方块或附件占用，会保留原方块并报告空间问题，不能强行吞掉建造内容；清出对应空间后再刷新／用扳手修复。新教学地图完整验证新形状。

## 开发期检查

`tools/refine_model_surfaces.py` 在原模型生成后执行；`tools/test_model_surfaces.py` 检查裁切面积、UV、透明保护及重复执行稳定性。`tools/refine_plant_alarm.py` 重新生成柔和提示音，通用音频检查继续验证全部 37 段音频。

`runInterfaceQa` 使用独立开发期 source set，在真实 Minecraft 客户端渲染手册与 PCB，直接验证鼠标事件、缩放锚点和窗口调整，导出截图与报告；不需要桌面自动操作，不载入玩家存档，不进入发行 JAR。游戏内测试另外检查四个朝向的核电管道端点和机组碰撞、供电及物流。客户端截图仍不能代替用户所装全部光影／界面模组组合的兼容性体验。
